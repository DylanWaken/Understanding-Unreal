Exponential moving average (EMA)

Mathematics

A smoothed estimate updated as previous estimate plus alpha times the difference between a new sample and that estimate. Older samples receive exponentially decreasing weight; this is not a fixed-size window average.

In Ardashir: ArdaInductor initializes each node estimate from its first completed timing sample, then updates it in collection order. The default alpha of 0.2 gives each new sample 20 percent weight. Adaptive scheduling can use these estimates, while raw timing history is stored separately with a bounded capacity.
