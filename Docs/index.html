The essays

Start with the room to see how the pieces fit together, or go straight to the rendering problem you want to study. Each essay starts from first principles and follows them into the engine.

Scene representation

Scene Representation in Unreal Engine

A hinged door swings, a mannequin bends at its joints and several plants share one mesh. Follow those objects from components and shared geometry into render proxies and GPU Scene records. The room shows how animation changes what the raster passes draw and what the lighting system sees.

Virtual geometry

Nanite: From a Scanned Bunny to Visible Pixels

Build a cluster hierarchy from the Stanford bunny and measure it. The experiment follows detail selection, page streaming, occlusion tests and visibility rasterization, then compares the results with Unreal's Nanite builds and captures.

Global illumination

Building Lumen: From Light Paths to a Real-Time Atrium

A path estimator can spend as long as it needs on the light falling into Sponza's shaded arcade. What can it reuse when it has only one frame? The diagrams and interactive experiments use the atrium in Unreal to explain shadows, surface caches, probes and reflections.

Continue into the implementation reference and its controlled-room frame explorer for stored values, packed fields and pass parameters.

Material compilation

How Unreal Compiles a Material Graph

Follow an expression from the Material Editor to the GPU program that shades a surface. Along the way Unreal analyzes the graph, translates it to HLSL, generates shaders, chooses permutations and caches the results.

Source, evidence and reproduction

Engine source

The source links point to the inspected lines at commit 71fe36aac5a8. You need access to Epic's Unreal Engine repository to open them. Captions identify screenshots and presentations from older versions.

Reproducible laboratories

The Nanite, Lumen and scene labs include the generators, scene descriptions, measurements and hashes of the recorded outputs. Run validate_labs.py to check that evidence on a machine without a GPU or scientific Python stack.

Offline mathematics

The build uses a bundled copy of KaTeX and a checked-in equation cache to produce the same HTML and MathML each time. The fonts ship with the pages, so equations also work offline.

Using this site

Navigate the chapters

Each essay starts with a rendering problem. The numbered chapters develop the representation, the algorithm and its cost. The site also offers chapter navigation, a reading-position indicator and a dark theme.

Check the evidence

Open a figure for the full-size original. Tables give the recorded measurements, and source lists point to the lines of engine code behind them. The migration record lists what moved to this site and what stayed in the original repository.

Look up a term

Each term links to its entry in the graphics glossary, even with JavaScript disabled. With JavaScript enabled, hover over the term or focus it with the keyboard to read its definition in place.
